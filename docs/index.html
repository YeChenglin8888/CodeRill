示意流程 · 不代表一次真实模型运行

真正值得研究的 Agent，应该能回答三个问题：

它为什么这么做？它改了什么？出错后能否恢复？

INSIDE THE LOOP

从一个循环，读懂整套系统。

功能围绕清晰的边界组织。沿着一次请求往下读，就能看见关键决策在哪里发生。

01 / EXECUTION

模型 ↔ 工具

流式接收模型回复；需要调用工具时执行并把结果送回模型。只读操作可并行，修改操作保持顺序。

agent.py · llm.py · tools/
02 / CONTROL

权限与改动预览

标准模式会在修改文件、执行命令或访问网络前询问。文件改动先展示 diff；文件工具会拒绝工作区外的路径。

permissions.py · review.py
03 / RECOVERY

可重放的会话

会话写入只追加的事件日志，支持恢复和分叉。任务计划也随日志保存，重新打开时保留进度。

session.py · taskplan.py

当前边界：Shell 命令尚未沙箱化；真实模型调用需要你自己的 API Key。

GET STARTED

一条命令，装进终端。

目前从 GitHub 源码安装。需要 Python、Git 和 pipx；配置 OpenAI 兼容接口的 API Key 后即可开始使用。

查看配置说明 ↗
01 · 安装pipx install git+https://github.com/YeChenglin8888/CodeRill.git
02 · 配置密钥OPENAI_API_KEY=你的密钥在系统环境变量或项目的 .env 文件中设置。
03 · 启动coderill

安装命令会从 GitHub 获取当前代码；PyPI 发布后会提供更短的版本化命令。
